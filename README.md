# Ramses

Your own AI assistant that runs on your PC: chats, files, code, pictures and boards, offline by default.

**Download:** see [Releases](https://github.com/damananders/Ramses/releases), or the page at https://damananders.github.io/ramses/

1. For local models, install [Ollama](https://ollama.com) (free). Without it, Ramses works with an online key.
2. Unzip the release and double-click `Install Ramses.cmd`. It installs for your Windows account only, no administrator rights needed.
3. Open Ramses from the desktop. The setup explains each choice and offers to download the models picked for your PC.

Windows 10 or 11, 64-bit. Check the download against the SHA-256 listed with each release. MIT licensed.
